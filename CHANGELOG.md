# Changelog

Los cambios relevantes de RutaCuadrilla se documentan en este archivo.

## 0.1.0 - 2026-08-29

### Added

- Edición pública de portafolio con datos geográficos sintéticos.
- Perfil de API reducido para el flujo Simple Online.
- Documentación de seguridad, contribución y procedencia de datos.

### Changed

- La experiencia principal se centra en administración, asignación y registro
  de visitas en línea.

### Removed

- Datos territoriales y runbooks operacionales del piloto privado.
- Publicación del shell offline experimental en el artefacto principal.
